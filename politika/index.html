Политика конфиденциальности

Коротко о том, какие данные сайт собирает и что с ними происходит.

Какие данные собирает сайт

Сайт состоит из обычных страниц с текстом и картинками. Форм для отправки данных на нём нет, регистрация не предусмотрена, личные сведения посетителей сайт не запрашивает и не хранит.

Файлы cookie и статистика

Собственных файлов cookie сайт не устанавливает. Счётчиков посещаемости на страницах не подключено.

Внешние сервисы

Шрифты подгружаются с сервиса Google Fonts, поэтому при открытии страницы браузер обращается к его серверам и передаёт им технические данные запроса, включая IP-адрес. Это делает сам сервис, по своим правилам.

Кнопки со страниц ведут на телеграм-канал школы и на профиль в Instagram. После перехода действуют правила этих площадок.

Обращения в телеграм

Написанное Ирине остаётся в самом мессенджере и хранится по его правилам. Содержание обращений используется только для ответа и для работы по обучению.

Изменения

Если на сайте появятся формы или счётчики, этот документ будет дополнен до их подключения.
